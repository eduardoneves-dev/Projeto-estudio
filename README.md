# Ana Neves | Nail Designer

Landing page desenvolvida para apresentar o estúdio de unhas Ana Neves, destacando seus serviços, equipe, história e informações para agendamento.

🔗 **Acesse o projeto:** [Ana Neves | Nail Designer](https://eduardoneves-dev.github.io/Projeto-estudio/)

## Sobre o projeto

O projeto consiste no desenvolvimento de um site comercial para um estúdio de Nail Design, com uma interface moderna, elegante e responsiva, proporcionando uma experiência intuitiva aos visitantes.

O objetivo é fortalecer a presença digital do estúdio, apresentar seus serviços e facilitar o contato com as clientes.

## Funcionalidades

- Página inicial com apresentação do estúdio.
- Seção com a história da empresa.
- Apresentação da equipe e dos serviços oferecidos.
- Informações de localização e horário de funcionamento.
- Seção de dúvidas frequentes (FAQ).
- Integração com WhatsApp para agendamento.
- Layout adaptável para dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
